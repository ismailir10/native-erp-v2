# BUG-014 — Long unbroken text overflows its card; duplicated word in a toast

| | |
|---|---|
| **Severity** | Low |
| **Status** | **Fixed** (branch `task/fix-qa-bugs`) |
| **Area** | Cosmetic |
| **Test cases** | R4 · L1 |

## Steps to reproduce
1. Ask Tanya Buku a 2,000-character question with no spaces.
2. Register a lease named “Sewa Gudang QA”.

## Expected
Text wraps/truncates; toast reads “Sewa Gudang QA didaftarkan”.

## Actual
The echoed question runs past the card edge; toast reads “Sewa **Sewa** Gudang QA didaftarkan”.

## Root cause
Missing `break-words` on the echo; the toast prefixes “Sewa ” to the name.

## Impact
Cosmetic.

## Suggested fix (original)
`break-words` / `overflow-wrap:anywhere`; drop the redundant prefix.

## Evidence

![R4-tanya-too-long.jpg](../screenshots/R4-tanya-too-long.jpg)

## Fix applied

`break-words` / `overflow-wrap:anywhere` on the Tanya Buku question echo; lease toasts no longer repeat “Sewa” (`leaseLabel`).

**Regression guard:** Browser (`VF-014a/b`).

**Re-verified in the browser:** case `VF-014` in [results-table.md](../results-table.md).
