# BUG-013 — Every page has the same `<title>`

| | |
|---|---|
| **Severity** | Low |
| **Status** | Open |
| **Area** | Accessibility / navigation |
| **Test cases** | Y3 |

## Steps to reproduce
1. Open any two pages and compare `document.title`.

## Expected
A distinct title per page (e.g. “Neraca Saldo · CV Sinar Retail · Buku”).

## Actual
“Buku · tutup buku bulanan untuk kantor akuntan” on all 18 pages sampled.

## Root cause
Only the root layout defines metadata.

## Impact
Browser tabs/history and screen-reader page-change announcements are indistinguishable.

## Suggested fix
Add `generateMetadata`/`metadata` per route.
